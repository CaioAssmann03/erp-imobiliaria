# Help assistant (N — Norms)

`components/assistant/` (client): `AssistantChat` (the header button + the window), `AssistantPanel` (the window), `useAssistantConversation` (the conversation and the generated mutation `useAssistantAskCreate`) and `assistant-copy.ts` (every Portuguese text).

- **Only inside the ERP, only logged in.** An ink button with the word *Ajuda* (`rounded-button`: the design system has no round buttons, a test enforces it) fixed at the **bottom right** of the screen (`AssistantChat`, mounted at the end of `AppShell`, `z-40`), which opens the window as a side panel (`z-50`), docked to the right edge at full screen height (`fixed inset-y-0 right-0`, full width on a phone, `sm:w-112` otherwise, no backdrop, slides in with `animate-in slide-in-from-right`, a CSS animation the lite mode cuts) and covering the button, calling `/api/assistant/ask/`. **The public pages and the login have no chat, and the backend has no anonymous endpoint** (user decision, 2026-11-02): do not add one without a new spec.
- **The user can turn it off:** *Configurações → Assistente* (`settings/AssistantSection.tsx`, a `SettingsSwitch`). The choice is kept in this browser (`localStorage` key `assistant-enabled`, `useAssistantEnabled`, on by default; the same pattern as `useRailExpanded`) and, when off, neither the button nor the window is drawn. Until the client takes over the state is off, so a person who turned it off never sees the button flash; whoever keeps it on sees it appear right after the page loads. "Restaurar padrão" does not touch it.
- **The warning is always visible** at the bottom of the window (`ASSISTANT_COPY.notice`, short: no CPF, CNPJ, e-mail, phone, boleto numbers or residents' names; the assistant does not see the registers and can be wrong). It is half of the contract: the backend filter refuses what it can detect, and the screen shows that error in Portuguese (`assistant_question.question.sensitive_data` in `lib/errors/error-messages.ts`). The client does not repeat the filter: the backend is the only judge.
- **A question joins the conversation only when its answer arrives.** If it is refused (sensitive data, rate limit, unavailable) it stays in the field to be fixed and the error shows under the conversation. Each request carries the question plus the last 6 messages of the conversation (`history`, `HISTORY_LIMIT` in `useAssistantConversation.ts`, the backend's limit, spec 069 R13), so the assistant understands a follow-up; because a refused question never joins the conversation, the history sent is always whole exchanges. The conversation lives only in the component's state: nothing is stored, on the screen or on the server. It is held by `AssistantChat`, not by the panel, so closing and reopening the panel keeps it; it is lost when the page is reloaded. Answers are rendered as plain text (`whitespace-pre-wrap`), never as HTML.
- **Look of the window** (`AssistantPanel`), the same language as the dashboard cards: a square-cornered full-height panel with `shadow-float` and a light header like the Settings window's (`text-title`, one line of support text, the X), and it stands apart from the page through the `surface-muted` conversation area and the shadow, in both modes; the conversation on `surface-muted` with the question in a `brand-soft` bubble on the right and the answer in a white `surface` bubble (`shadow-card`) on the left; with no conversation yet, a welcome line and three example questions (`ASSISTANT_COPY.suggestions`) as white rows that are sent with one click; the field in a `rounded-control` well with the send button; the sensitive-data notice under it, always visible. **No sparkle/AI-style icons or emoji**, no divider lines.
- Tokens only (`rounded-panel`, `rounded-control`). The accent (`brand`, so it follows the chosen color) is used only where it means something: the user's own question bubble (`brand-soft`, a faint tint) and the send button (`brand` when there is text to send, grey when not; the one exception to the ink primary button), plus the focus rings. No decorative accent (top bars, colored dots, tinted hovers) and no colored icon on the *Ajuda* button. The only motion is the pulse of the three "thinking" dots, a CSS animation that the lite mode already cuts (the dots stay still and the `sr-only` text remains).
